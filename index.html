What people think AI is

🤖 Terminator

🔮 A magic oracle

🧠 A conscious mind

What it actually is:

Autocomplete that read the whole internet.

Extremely good at patterns. Terrible at knowing what it doesn't know.

What's an AI agent?

A chatbot that can take actions, not just talk.

  • 🌐 Browse the web & read real pages
  • 📁 Write files & run code
  • 📨 Send things — emails, posts, PRs

Chat = answers. Agent = work gets done.

How far it's come

Week-long task→one afternoon
3 days of contract boilerplate→20 minutes to review
"We need a landing page"→live before lunch

Same human. Same week. Different leverage.

How to spot AI BS

🚩 Red flags

  • "AGI is coming next year"
  • "AI will replace all jobs"
  • Perfect, slick demos — cherry-picked
  • "Powered by AI" as the feature itself

✅ Green flags

  • Shows real, raw output
  • Admits what it got wrong
  • Shows the workflow, not the magic
  • Boring claims you can verify

AI fails. Confidently.

"Absolutely certain." — wrong

It will invent sources, dates, numbers — fluently.

Lesson: always verify.

Where AI genuinely works today

  • ✍️ Writing — drafts, edits, tone
  • 📋 Summarizing — long → short
  • 💡 Brainstorming — 20 ideas in 20 seconds
  • 📚 Learning — a patient tutor on any topic
  • 🗂️ Admin — emails, plans, boring paperwork

Where it still sucks

  • ❌ Facts from memory — it will hallucinate
  • ❌ Math in chat — ask it to run code instead
  • ❌ High-stakes judgment — legal, medical, money

Use it as a first draft, never the final call.

The one skill: prompting

Being a good manager, not a good typist.

  1. 🎯 Give context — who you are, what's going on
  2. 📄 Give an example — "like this"
  3. 🏁 Define "done" — format, length, quality bar

You wouldn't brief an intern with one word. Same rule.

Try it yourself — copy, paste, go

1 · Write in your own voice

You are my writing assistant. I'll paste a sample of my own writing below. Learn my voice from it: word choice, rhythm, level of formality.

Then write a [job application email / intro message] for me applying to [role / opportunity]. Audience: [who reads it, e.g. a startup founder in Turku]. Keep it under 150 words, no corporate fluff, no "I am excited to leverage".

My sample writing:
"[PASTE 2-3 PARAGRAPHS OF YOUR OWN WRITING HERE]"

Details I must include: [YOUR 2-3 KEY FACTS]

2 · Tame a boring PDF

Summarize the attached document.

Format exactly:
• 5 bullets — the key points, one line each, plain language
• 3 questions I should ask next — things the document leaves open or that would matter to me

Rules: no jargon unless it's in the document, don't invent facts, if something is unclear say so instead of guessing.

3 · Plan something iteratively

Help me plan [a trip to X / my event / my week].

Constraints:
- Budget: [amount]
- Time: [dates / hours]
- Who: [people involved]
- What matters most: [top priority]

First, ask me up to 3 clarifying questions if anything important is missing. Then give me a draft plan as a simple day-by-day (or hour-by-hour) outline. Mark anything you're unsure about with [?]. After that I'll push back and we'll iterate.

4 · One sentence → tiny webpage

Write me a complete, single-file HTML page (HTML + CSS + JS all inline, no external dependencies).

The page: [YOUR ONE-SENTENCE IDEA, e.g. "a landing page for my cat-sitting side hustle with a price list and a fake booking button"]

Keep it under 200 lines, dark modern theme, mobile-friendly. Output ONLY the code in one code block so I can copy-paste it into a .html file and open it in my browser.
